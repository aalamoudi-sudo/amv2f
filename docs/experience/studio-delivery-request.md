# Studio Delivery Request For Experience Twin Inputs

## Native Source Package

Provide the editable native source appropriate to the studio workflow:

- SketchUp (`SKP`), 3ds Max (`MAX`), Revit, or Blender source;
- all linked textures, materials, fonts, proxies, and external assets;
- GLB/GLTF export for review;
- editable AI/SVG visitor map and icon library;
- source version, revision history, approval status, and issue date;
- rights confirmation for display, editing, internal distribution, and future
  output generation.

Do not flatten away object hierarchy or stable IDs.

## Spatial Metadata

- Units and verified scale.
- Model origin and axes.
- North direction.
- Coordinate/reference status.
- Named objects and parent hierarchy.
- Existing Mayadeen zone/entity IDs on applicable objects.
- Registration/control points and their authority.
- Explicit statement when geometry is conceptual rather than surveyed.

## Cameras And Journey

- Named camera positions with purpose and target persona.
- Proposed camera path as a candidate, not an approved physical route.
- Day/night variants where relevant.
- Lens, exposure, and render settings.
- Reference stills linked to source objects and revisions.

## Panorama Package

- 8K equirectangular images at approximately 8192×4096 and 2:1.
- One immutable file fingerprint and revision per panorama.
- Location/entity/zone and journey-step bindings.
- Camera heading and pose status.
- Day/night variants where relevant.
- Rights and approval status.
- Confirmation that each file is a true panorama, not a perspective render or
  AI-filled view.

## Visitor Map

- Editable AI or SVG.
- Arabic and English labels.
- Attraction, entry/exit, accessibility, amenities, service, VIP, media,
  security, first-aid, prayer, food, toilet, and information hierarchy.
- Icon and color systems.
- Revision and authority.
- Registration method to future approved spatial control.

Delivery enables validation and candidate review only. It does not itself
approve geometry, readiness, routes, safety, or operation.
