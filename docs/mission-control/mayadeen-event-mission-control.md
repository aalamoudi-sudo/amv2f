# Mayadeen Event Mission Control

## وعد المنتج

`Mayadeen Event Mission Control` يقدم الفعالية كعالم حي واحد، لا كمجموعة منصات
متجاورة. يختار المستخدم مشروعًا وفعالية ويومًا وشخصية ورحلة ولحظة وكيانًا، ثم
ينظر إلى الاختيار نفسه عبر التجربة والمكان والتشغيل والقرار والمستقبل.

المبدأ الحاكم:

`ONE OBJECT -> MANY LENSES -> ONE TRUTH`

## حلقة KAP الذهبية

المسار المؤسس الحالي هو:

1. مشروع تدشين حدائق الملك عبدالله.
2. 31 أكتوبر 2026.
3. الموظفون وعائلاتهم مع مرشح العاملين V.11.
4. التسلسل السردي إلى ممر العصور.
5. `ENTITY-KAP-OP-006` و`ZONE-AGES-TUNNEL-001`.
6. مشتق Web3D المتحقق `DESIGN-ASSET-KAP-DIRECT-MESH-001`.
7. كشف ما وراء التجربة للكيان نفسه.
8. سياق التشغيل، ثم القرار، ثم البروفة والمخرج المادي التصوري.
9. العودة إلى عدسة التجربة دون فقد الاختيار.

V.11 يظل `received-validated-working-candidate` ولا ينشئ `SpatialRoute`. مشتق
Web3D يمثل نية تصميم وافق المؤسس على استخدامها كمصدر تصميمي، لكنه غير مسجل
هندسيًا وليس as-built أو 360 أو دليل جاهزية. علاقة المشهد بممر العصور تبقى
`proposed / medium`. جاهزية KAP تبقى `cannot-determine`.

## أعماق العرض

| العمق | الغرض | ما يبقى مخفيًا افتراضيًا |
|---|---|---|
| عرض العميل | القصة واليوم والشخصية والخريطة وWeb3D | المعرفات والبصمات والمصفوفات التقنية |
| مركز القيادة | الاستثناءات الثلاثة الأهم والجاهزية والقرار والدليل | تفاصيل المخططات والمحولات |
| المختبر التقني | المصدر والإصدار والعقود والبصمات والتشخيص | لا شيء تقني، مع بقاء الأصول الخاصة خارج المتصفح |

الأعماق الثلاثة تستخدم `MissionContext` والإسقاط نفسه؛ تغيير العرض لا ينسخ
الحقيقة ولا يغيرها.

## ما يعمل وما ينتظر

- يعمل الآن: السياق الموحد، العدسات الخمس، خريطة القصة، رحلة V.11 المرشحة،
  Web3D الحقيقي، كشف التشغيل، سياق القرار، البروفة الرقمية، ومعاينة المخرج
  المادي.
- غير متصل: مصدر حي لـKAP، محرك محاكاة، مخزن أدلة إنتاجي، هوية ووقت موثوقان،
  أجهزة أو بوابة إسقاط.
- غير موجود: بانوراما KAP حقيقية، مسار مكاني معتمد، تسجيل هندسي، اعتماد HSE،
  قرار افتتاح، أو جاهزية تشغيلية مؤهلة.
- `MissionAdvisor` عقد مستقبلي قابل للاستبدال فقط؛ لا مزود AI ولا توصية آلية.

## حدود التشغيل

كل اعتماد أو تحقق أو تغيير جاهزية أو مسودة قرار قانونية يظل خلف البوابات
القائمة. Mission Canvas لا يكتب إلى الخط الأساسي، ولا يتحكم في جهاز، ولا
يحوّل الرصد أو البروفة أو العرض إلى حقيقة تشغيلية.
