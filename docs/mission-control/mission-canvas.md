# Mission Canvas

## التركيب

`MissionCanvas` طبقة عرض داخل `workspace=experience-twin` عند
`mission=canvas`. ليست Workspace جديدة ولا Runtime ثانيًا. تتكون من خمس مناطق
دائمة فقط:

1. شريط السياق: المشروع واليوم والشخصية واللحظة والوضع والعدسة وعمق العرض.
2. المسرح المركزي: الخريطة أو Web3D أو كشف التشغيل أو القرار أو المستقبل.
3. شريط الآن: ثلاثة عناصر كحد أقصى في مركز القيادة.
4. خط الزمن: `خطط -> جهّز -> تدرّب -> شغّل -> تعلّم` مع أيام KAP الأربعة.
5. حقيقة المصدر: شارة واحدة ودرج عند الطلب.

المسرح المركزي يحتل المساحة الأساسية. عرض العميل يخفي شريط الاستثناءات، بينما
يبقي الحقيقة على بعد إجراء واحد.

## رحلة الكشف الحي

زر `ابدأ الرحلة` يفتح التسلسل المرشح فوق المرجع المكاني الحقيقي. النقاط ذات
العلاقة الصريحة تظهر كوجهات سردية، والخط منقط وموسوم
`الربط المكاني غير محسوم`. اختيار ممر العصور يزامن خطوة الرحلة والكيان والمنطقة
ثم يتيح Web3D عبر العلاقة الصريحة فقط. لا يرسم Canvas هندسة أو مسافة أو بوابة
أو اتجاهًا.

داخل Web3D، يبقى النموذج هو البطل وتبقى شارة المصدر والتحكم بالجولة في العارض
القائم. `عرض ما وراء التجربة` لا ينتقل إلى Dashboard منفصل؛ إنه يبدل العدسة
فوق الكيان نفسه.

## الحالات الصادقة

- `live`: يعرض `لا يوجد مصدر حي متصل` عند غياب المصدر.
- `future`: يعرض `محرك المحاكاة غير متصل` مع فصل البروفة عن المحاكاة والتوقع.
- 1 نوفمبر: يظل يومًا ظاهرًا، وتظهر الرحلة المشتركة `not-applicable` بلا خط أو
  مدة أو fallback.
- المشهد المفقود: لا يحمّل مشهدًا تجريبيًا بديلًا.
- السياق غير الصالح: رسالة عربية آمنة بلا انتقال إلى مشروع أو يوم آخر.

## Tangible Command Surface

المعاينة تستهلك `projectionVersion` نفسه الصادر عن إسقاط البروفة، وتعرض أهدافًا
مستقبلية للمجسم والإسقاط وجدار القيادة وطاولة اللمس. الحالة الحالية دائمًا:

- `preview-only` أو `unavailable`.
- `not-calibrated`.
- لا جهاز متصل.
- لا تحكم عتاد.
- لا ادعاء مطابقة.

المرجع الإلزامي هو `MEIOS-PDT-STD-001 v1.0.0`. لا يوجد Deployment Profile أو
Model Manifest أو Calibration Profile أو إذن Stage 6 في هذا الإصدار.

## الوصول والاستجابة

الواجهة عربية RTL، تدعم التركيز المرئي ولوحة المفاتيح و`prefers-reduced-motion`،
واختُبرت عند `1366x768` و`1920x1080` و`2560x1080`. شريط السياق والخط الزمني
لا يغطيان النموذج أو نقاط الخريطة التفاعلية.
