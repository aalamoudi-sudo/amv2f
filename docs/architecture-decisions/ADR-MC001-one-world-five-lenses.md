# ADR-MC001: One World, Five Lenses

- Status: Proposed for founder review
- Date: 2026-08-02
- Scope: Mission Canvas RC1

## Context

تملك Mayadeen محركات وتجارب ناضجة للتجربة والمكان والجاهزية والقرار والبروفة،
لكن الانتقال بينها كان يمكن أن يبدو كخمس منصات ويفقد المستخدم اللحظة والكيان.
إنشاء Workspace أو Store جديد لكل عدسة كان سيكرر الحقيقة ويزيد خطر التسرب أو
ترقية بيانات KAP المرشحة.

## Decision

نعتمد مبدأ `ONE OBJECT -> MANY LENSES -> ONE TRUTH`:

- `ExperienceSelectionContext` يبقى هوية الاختيار القانونية الحالية.
- `MissionContext` يضيف الوضع والعدسة وحقيقة المصدر ونسخة الإسقاط.
- `MissionGraphProjection` يجمع الإسقاطات القائمة للقراءة فقط.
- `MissionCanvas` تركيب عرض واحد داخل Experience Twin.
- العدسات الخمس لا تملك مخازن حقيقة مستقلة.
- أعماق العميل والقيادة والمختبر تغير الإفصاح، لا البيانات.
- كل طفرة قانونية تبقى خلف Action Gateway أو البوابة المتخصصة القائمة.

## Consequences

يمكن للمستخدم دخول ممر العصور ثم كشف تشغيله وقراره وبروفته دون فقد الكيان.
الرابط العميق وتاريخ المتصفح يحملان السياق نفسه. التوسع إلى Backend مستقبلي
يستبدل مستودع قراءة الإسقاط، لا عقود المجالات.

تظل KAP `cannot-determine`، وV.11 مرشحًا، وWeb3D غير مسجل هندسيًا. وضع `live`
لا ينشئ مصدرًا حيًا، وعدسة المستقبل لا تنشئ محاكاة.

## Physical and AI boundaries

`Tangible Command Surface` Preview فقط، ملتزم بمرجع
`MEIOS-PDT-STD-001 v1.0.0` ولا يملك معايرة أو عتادًا أو ادعاء مطابقة.
`MissionAdvisor` Interface فقط بلا مزود AI. لا SDK لمورد خارجي في القرار.

## Rejected alternatives

- خمس Workspaces جديدة: مرفوضة لأنها تكرر السياق والتنقل.
- Store مخصص للعرض: مرفوض لأنه ينشئ حقيقة موازية.
- تحويل V.11 إلى Route لعرض أجمل: مرفوض لأنه يختلق تسجيلًا مكانيًا.
- ربط محاكاة أو AI أو عتاد في RC1: مرفوض لغياب المرحلة والبيانات والسلطات.
