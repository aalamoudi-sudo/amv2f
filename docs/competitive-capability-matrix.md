# Competitive Capability Matrix

## Reading the Matrix

This matrix compares current Mayadeen evidence with benchmark categories. It is a decision aid, not a claim that Mayadeen exceeds any global platform.

Current maturity labels:

- **Foundation:** Present in the current local product or documented contract.
- **Briefing-ready:** Useful for spatial briefing or exercise review, but not operational truth.
- **Research only:** Direction is defined; implementation is intentionally deferred.
- **Absent:** Not implemented and not currently a product claim.

All stages are roadmap targets, not commitments to expand the active sprint. Every researched implementation requires Ahmed's explicit approval.

## Strategic Interpretation

The matrix shows a gap in operational integration rather than a need to reproduce every benchmark layer. The recommended order is:

1. Strengthen open spatial and evidence contracts.
2. Validate Event Ontology and decision traceability with one real decision.
3. Prove scenario-to-action and closure measurement before adding live inputs.
4. Add specialized sensors, simulation, workflow engines, spatial computing, or physical interfaces only when a measured operational problem and Ahmed-approved experiment justify them.

## Claims Boundary

Current Mayadeen claims must remain limited to the documented local Arabic RTL spatial decision and operational exercise interface. The matrix does not authorize claims of live data, calibrated projection, verified readiness, simulation, prediction, computer vision, indoor location, workflow durability, or cross-event learning.
