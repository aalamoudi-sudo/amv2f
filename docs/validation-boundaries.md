# حدود التحقق والادعاء

حدود Stage 3D للالتقاط والتكامل معرفة في `docs/stage-3d-validation-boundaries.md`. سجل الأحداث المحلي ومحرك الثقة وAdapters وقائمة offline والمعاينات الجغرافية والمادية أدوات تحقق معماري فقط؛ لا ترفع حالة ادعاء جاهزية Stage 3A أو قرارات Stage 3B/3C.

## وظيفي الآن

- تحقق محلي typed لثماني مناطق تجريبية.
- مؤشرات zone-specific، طابور تدخل، تفاصيل المنطقة، أثر الاعتماديات والمسارات.
- تعديل محلي مع revision و`changeReason` وعزل السيناريو عن الأساس.
- منع الاعتماد المحلي عند غياب الدليل أو معلومات المعتمد.

## Demo-only

بيانات المناطق الثماني، المصادر التجريبية، التعديلات في المتصفح، حالات الاعتماد المحلية، وخطوط المسارات غير المعتمدة. هذه لا تمثل readiness verified أو route approval أو live digital twin.

## يتطلب بيانات تشغيلية حقيقية

مصادر موثوقة لكل منطقة، مالك ومسؤول، أدلة قابلة للفحص، تواريخ محدثة، اعتماديات فعلية، أثر افتتاح ومسارات مصادق عليه، وهندسة مسارات بإصدار.

## يتطلب سلطة رسمية

اعتماد السلامة، اعتماد مسارات الإخلاء، قرار فتح منطقة، التوقيع على الأدلة، وتصعيد الحدث. الواجهة الحالية تعرض فجوة السلطة ولا تمنحها.

## مؤجل لاحقاً

Backend، هوية وصلاحيات، سجل تدقيق، مزامنة متعددة المستخدمين، storage للأدلة، adapters، live feeds، cameras، sensors، AI prediction، simulation engine، وphysical calibration.
