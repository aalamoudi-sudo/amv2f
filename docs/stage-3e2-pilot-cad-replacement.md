## مسار الاستبدال

`Stage source` → `validate` → `compare` → `explicit engineering approval` →
`promote atomically` → `rollback on any dependency failure`.

الترقية ترفض:

- مصدر غير معتمد أو بلا بصمة أو مراجعة.
- وحدة غير المتر.
- غياب EPSG أو الشمال أو الأصل.
- فقد أحد المعرّفات الخمسة أو ظهور ربط يتيم.
- استخدام اعتماد المنصة بدل الاعتماد الهندسي.
- فشل أي تابع.

عند الفشل يبقى البيان السابق نسخة دفاعية بلا تغيير. لا يمس الاستبدال `eventId`
أو `venueId` أو الحوكمة أو الأدلة أو سجل القرارات. لا يوجد هنا تحويل DWG أو SDK.
