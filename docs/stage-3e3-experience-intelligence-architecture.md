# Stage 3E.3 — بنية ذكاء تجربة الفعالية

## القرار المعماري

تضيف Stage 3E.3 طبقة `ExperienceIntelligencePack` عامة فوق عقود الفعالية الحالية، من دون إنشاء runtime تشغيلي منافس. الحزمة تعرض تجربة مرشحة وتربطها بمعرفات الكيانات الثابتة، لكنها لا تفعّل EventPackage ولا تكتب إلى baseline أو scenario.

## الحدود

- **المحرك العام:** العقود والتحقق وحالة الاختيار وتشغيل القصة ومعاينة العرض.
- **الإعداد:** أسماء KAP ومصادرها وتسلسل النقاط وحالات الثقة موجودة في ملفات البيانات فقط.
- **الحالة:** اختيار النقطة والوضع والتشغيل حالة واجهة مؤقتة داخل مساحة العمل.
- **المكان:** الصورة المبدئية سياق بصري فقط؛ لا تُحوّل إلى إحداثيات أو هندسة.
- **الإسقاط:** معاينة قصة نظيفة فقط، منفصلة عن إسقاط التشغيل والمعايرة المادية.

## تدفق البيانات

`Pilot candidate sources → ExperienceIntelligencePack → validator → lazy workspace → Experience / Command / Story views`

كل الأوضاع تستهلك الحزمة نفسها ومعرف النقطة نفسه. لا يوجد شرط في Core يعتمد على `EVENT-KAP-OPENING-2026`، وتثبت حزمة مؤتمر مستقلة قابلية إعادة الاستخدام بعدد نقاط وتسلسل مختلفين.

## الأداء

تُحمّل بطاقة الدخول ومساحة التجربة والعقد والبيانات عند الطلب. الأصل المحلي المقيد يُكتشف وقت البناء من موضع gitignored؛ غيابه ينتج حالة نقص مقصودة ولا يكسر البناء.

## ما لم يتغير

تبقى ضمانات Stage 3C.1 وStage 3D.1A وStage 3E.1 وStage 3E.2 كما هي: فصل السياقات، نزاهة القرار، الإثبات والمنشأ، التفعيل الذري، والحماية من تسرب البيانات بين الفعاليات.
