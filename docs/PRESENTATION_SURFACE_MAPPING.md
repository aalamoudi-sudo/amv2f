# KAGA V2.1 PF-2 Presentation Surface Mapping

## Scope

This mapping is the implementation authority for presentation archetype
selection in PF-2. It was completed before visual propagation. It does not
change content, source meaning, route geometry, spatial registration,
`pathProgress`, knowledge data or interaction state machines.

The four approved source page archetypes remain:

1. **Editorial / Render** - dominant source image, cream title field, controlled
   green/teal contour and gold hairline.
2. **Route / Map** - dominant spatial surface, quiet right information column,
   thin rules and minimal contour obstruction.
3. **Event Day / Chapter** - selected ceremonial chapter, date hierarchy,
   compact facts and framed source imagery.
4. **Quiet Identity** - extensive negative space, sparse objects, thin rules and
   little or no organic contour.

Presenter Mode uses a fifth implementation state, **Minimal Shell**. It is not a
new page archetype; it removes interface chrome while preserving the archetype
of the active content.

## Control and contour rules

- Strong organic contour: Editorial / Render only, plus the frozen Event Day
  composition.
- Minimal edge: Route / Map only.
- No contour or a hairline-only accent: Quiet Identity.
- Orange: active chapter, selected micro-label or protocol emphasis only.
- Secondary actions: text plus a thin gold rule unless a solid primary action is
  required for interaction clarity.
- Source chips and provenance remain hidden in executive mode.

## Frozen contracts

PF-2 does not modify the PF-1.1 Intro, Four Days or Masterplan/Journey
composition. It also does not alter the six journeys, registered Gardens,
Crescent unresolved status, source assets, knowledge model, Presenter keyboard
logic, Mobile Exhibition state machine, Invitation workflow, Royal sequence or
Launch sequence.
