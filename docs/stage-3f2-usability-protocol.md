# Stage 3F.2 Usability Protocol

This protocol is privacy-safe and does not assume real-source availability.

## Tasks

1. Open the correct event.
2. Find the external source pilot surface.
3. Identify whether the source is connected or only ready.
4. Identify the latest reported observation if one exists.
5. Determine freshness and trust.
6. Find the affected zone.
7. Switch between list, 2D, and 3D.
8. Explain why the observation is not verified truth.
9. Diagnose disconnect and recovery if applicable.
10. Create a manual decision draft only if the operator is authorized.

## Capture

- anonymized participant id
- completion
- completion time
- navigation path
- errors
- critical truth errors
- confidence rating
- operator notes

## Thresholds

- 90% task completion
- zero critical truth errors
- 100% recognition that telemetry is reported and unverified
- 100% correct identification of the affected zone
