# Event Theming Boundaries

## Stable Platform Identity

Mayadeen Operational Calm is stable across every event. Stage UX.1A does not use KAP or any other event package to style the platform core. KAP remains a candidate package and its labels, source constraints, and geometry qualification remain unchanged.

## Future Event Configuration

An approved event configuration may later provide an event logo, hero image, experience-storytelling accent, approved event typography, or projection branding. It may never override operational severity, truth classification, trust, approval status, safety colors, focus states, or accessibility tokens.

## Guardrail

Any future theme must be applied outside the core token contract, scoped to the event experience, documented with provenance and approval, and tested against event isolation. It must not alter browser deep links, global search scope, 2D/3D behavior, gateway states, or truth wording.
