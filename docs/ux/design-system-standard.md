# معيار نظام التصميم العربي RTL

**الحالة:** معيار واجهة داخلي قابل لإعادة الاستخدام. لا يمثل اعتماد هوية بصرية نهائية من أحمد.

## الأسس

| الفئة | المعيار |
| --- | --- |
| السطح | `--command-surface` و`--command-surface-raised`، مع حدود `--command-border` لتسلسل الطبقات. |
| النص | `--command-text` للنص الأساسي و`--command-muted` للسياق الثانوي. الخط العربي المفضل IBM Plex Sans Arabic ثم Tajawal ثم Noto Sans Arabic. |
| الدلالات | information أزرق، success أخضر، warning كهرماني، critical أحمر، وكل حالة مصحوبة بنص أو أيقونة أو عنوان. |
| المسافات | `4/8/12/16/24px` عبر `--command-space-*`، مع كثافة مريحة في التفاصيل وكثافة أعلى في مراكز القيادة. |
| الشكل | radius `6px`، حد واضح، ظل panel واحد، لا بطاقة زخرفية بلا وظيفة. |
| التركيز | outline أخضر `2px` مع offset `2px` لكل تحكم تفاعلي. |

## المكوّنات الموحدة

- `command-button` و`command-icon-button` للأفعال الوظيفية فقط، بحد أدنى `40px` للمس الهدف.
- `command-select` وحقول الإدخال بعناوين قابلة للوصول، ولا تعتمد placeholders وحدها.
- `command-card` و`command-action-card` لتدرّج اللوحات لا لإخفاء الحقيقة.
- `truth-badge` لحالة المصدر والسياق، مع نقطة ولغة نصية وليس لونًا فقط.
- حوارات البحث والدرج والتأكيد تحبس التركيز، تدعم Escape، وتعيد التركيز للمشغّل.
- حالات empty/loading/error/offline تشرح ما هو مفقود وما الذي لم يتحول إليه النظام.

## مفردات الحقيقة والثقة

| المصطلح | متى يستخدم |
| --- | --- |
| مرشح | حزمة أو تجربة لم تصبح أساسًا أو تشغيلًا معتمدًا. |
| بيانات تجريبية مؤقتة | محتوى محلي خيالي أو runtime تجريبي. |
| حالة أساسية | baseline صريح، لا يستنتج من مصدر آخر. |
| سيناريو | حالة تمرين أو عرض، لا واقع حالي. |
| مُبلّغ | ملاحظة واردة وغير متحققة، مثل Telemetry المقبولة من البوابة المحلية. |
| متحقق | نتيجة مرت مسار تحققها المعتمد، لا تستنتج من اللون. |
| محجور | تعارض أو قدم أو إدخال يحتاج مراجعة ولا ينتج حدثًا مقبولًا. |
| غير معروف | قيمة أو سياق غير محسوم. |
| غير متصل | مصدر محلي غير متاح؛ لا fallback صامت. |
| غير معتمد | لا توجد موافقة أو سلطة تحويل. |

كل رقم تشغيلي يعرض أو يفتح مصدره وطابعه الزمني وثقته وسياقه والدليل وحالة الاعتماد. لا يوصف gateway المحلي بأنه live، ولا توصف هندسة منطقية غير متحققة بأنها معتمدة.

## RTL والمعرّفات

- الوثيقة والحوار واللوحات RTL افتراضيًا.
- المعرفات، hashes، URLs، timestamps، units، code وIDs تستخدم `.ltr` و`bdi` عند اللزوم.
- الجداول تلتف فيها العربية الطويلة وتبقى المعرّفات LTR وقابلة للنسخ البصري.
- لا تظهر enums الإنجليزية الداخلية للمشغّل بلا تسمية عربية مفهومة.

## الحركة والاستجابة

الحركة انتقالية قصيرة وذات معنى فقط. عند `prefers-reduced-motion: reduce` تصبح الحركة والانتقالات `0.01ms`/دورة واحدة بلا تمرير إجباري. يظل المحتوى قابلًا للاستخدام عند `1366×768` و`1920×1080` و`2560×1080`، وتتحول اللوحات الجانبية عمدًا بدل قص المهام الأساسية.
