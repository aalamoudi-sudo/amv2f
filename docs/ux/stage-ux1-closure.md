# Stage UX.1: إغلاق تجربة القيادة العامة

## خط الأساس المحمي

- Stage 3F.1 كان مكتملًا ومختبرًا ومندمجًا fast-forward في `main` عند `a09dc5492a63b8f560383a52e179439f84ed6baf` قبل بدء UX.1.
- لم تتغير عقود gateway أو قاعدة SQLite أو API أو عقود Stage 3C.1 و3D.1A و3E و3F.0 و3F.1.
- لا تضيف UX.1 جهازًا أو broker أو cloud أو authentication أو صلاحيات إنتاجية أو Cesium أو Google أو AI أو simulation أو إسقاطًا ماديًا.

## ما تغير

1. أعيد تنظيم التنقل إلى القيادة والعمليات والمكان والتجربة والإدارة التقنية.
2. أنشئت قيادة تنفيذية تبدأ بمركز العمل الحرج، وتعرض حالة فارغة صادقة عند غياب حقيقة تشغيلية مفعّلة.
3. أنشئ تدفق مشغّل موحد مع disclosure تدريجي للمصدر والدليل.
4. أنشئت مساحة مكان بقائمة و2D و3D وهجين فوق اختيار عنصر مشترك.
5. أنشئ بحث عالمي محلي scoped للفعالية، يقبل العربية والإنجليزية والمعرفات الثابتة.
6. أنشئت إعدادات عرض تنفيذية وتشغيلية وتقنية، مع نص صريح بأنها ليست صلاحيات.
7. نُقلت المختبرات إلى درج إدارة تقنية واضح وظلت lazy-loaded.
8. وحّدت شارات الثقة وسلوك الحوارات وRTL والتركيز والحركة المخففة.

## حدود الحقيقة

- KAP وExperience Intelligence يظلان مرشحين ومعزولين. لا تنقل UX.1 الهندسة أو الحوكمة أو المصدر إلى baseline.
- المحاكاة المحلية والبوابة المحلية الدائمة تظلان مصدرين منفصلين. فشل البوابة لا يبدّل إلى المحاكاة.
- Telemetry المقبولة تبقى `reported` وغير متحققة، ولا تعدل readiness أو decisions أو baseline أو verified projection.
- اختيار العرض أو البحث أو التحديد المكاني لا ينشئ قرارًا أو اعتمادًا أو نتيجة تشغيلية جديدة.
