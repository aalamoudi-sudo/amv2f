# ملخص الوصولية: Stage UX.1

تحسنت UX.1 وصولية لوحة القيادة عبر RTL كامل، focus-visible، وصلة تخطي، حوارات مسماة محبوسة التركيز، اختصارات بحث لوحة مفاتيح، رسائل ثقة غير لونية، وحركة مخفضة. تؤكد اختبارات الوحدة والمتصفح هذه السلوكيات عند ثلاث دقات command-center.

هذا ليس اعتماد WCAG أو مراجعة قارئ شاشة. المتبقي: VoiceOver/NVDA، contrast review مستقل، لمس فعلي، تكبير متصفح، ومستخدمون ذوو احتياجات مساعدة. التفاصيل في `docs/ux/accessibility-review.md`.
