# عتبات قبول قابلية الاستخدام المقترحة

**هذه عتبات مقترحة بانتظار اعتماد أحمد واختبار مستخدمين فعليين. ليست نتائج محققة.**

| المعيار | العتبة المقترحة |
| --- | --- |
| تحديد الإجراء الأولي | خلال 10 ثوان. |
| العثور على كيان معروف | خلال 10 ثوان. |
| تفسير المصدر والثقة | صحيح في 90% من المهام المضبوطة. |
| خطأ سياق الحقيقة الحرج | صفر. |
| مراجعة قرار قياسية | تكتمل من دون مساعدة. |
| المختبر مقابل العملية الحية | لا يظن أي مشارك أن المختبر تغذية تشغيلية حية. |
| العودة إلى القيادة | تكتمل من دون فقد السياق أو حاجة لمساعدة. |

## قرار القياس

يعتمد أحمد حجم العينة والأدوار والفعاليات التجريبية قبل الدراسة. تفشل العتبة إذا ظهر خطأ حقيقة حرج واحد حتى لو نجحت بقية المهام، ويجب إصلاح الواجهة وإعادة الاختبار على عينة جديدة أو الجزء المتأثر.
