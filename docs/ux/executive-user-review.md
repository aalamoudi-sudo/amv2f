# مراجعة المستخدم التنفيذي: Stage UX.1

## نموذج الخمس ثوان

في القيادة تظهر هوية runtime وسياق الحقيقة، مركز العمل الحرج، الاعتمادات، العوائق، صحة المصدر والثقة، ومسار الأثر المكاني. عند غياب runtime لا تفبرك أرقامًا أو KPI وتعرض `لا توجد حقيقة تشغيلية مفعّلة` مع إجراء صريح.

## الإجابات

| سؤال التنفيذي | استجابة الواجهة |
| --- | --- |
| ما الذي أعرضه؟ | اسم runtime وسياق state/trust أو حالة فارغة صادقة. |
| ما الذي يحتاج الانتباه؟ | مركز العمل الحرج وعوائق منظمة. |
| ما أعلى أثر؟ | قرار أو عائق مرتبط بمنطقة ومسار مكاني. |
| هل المصدر صحي؟ | مصدر وثقة وسياق، أو إشارة إلى عدم الاتصال/النقص. |
| ما الخطوة التالية؟ | فتح العمليات أو القرار أو المكان من الإجراء المرتبط. |

## التحفّظ

هذا تحقق واجهة محلي، لا تحقق خمس ثوان مع مديرين حقيقيين. يجب قياسه في جلسات مضبوطة قبل اعتماد العبارة كنجاح استخدام فعلي.
