# Stage UX.1: مراجعة الوصولية

## ما اختبر محليًا

| المتطلب | الدليل المحلي |
| --- | --- |
| RTL ولغة عربية | `html` و`main` بالعربية و`dir=rtl` في اختبارات المتصفح. |
| لوحة المفاتيح | `Ctrl/Cmd+K`، الأسهم وEnter وEscape في البحث، وEscape في درج الإدارة التقنية وحوار التأكيد. |
| التركيز | focus-visible عام، وصلة تخطي إلى `#workspace-content`، حبس التركيز وإعادته في الحوارات. |
| الأسماء والعلامات | landmarks من `main` و`header` و`aside`، حوارات بـ`role=dialog` و`aria-modal` وعناوين مسماة. |
| الحالة غير اللونية | Truth badges وأوصاف الحالة النصية، بما فيها reported/quarantined/disconnected. |
| الحركة | اختبار Playwright لتفضيل reduced motion وCSS يخفف الانتقالات والحركة. |
| الاستجابة | اختبار عند `1366×768` و`1920×1080` و`2560×1080` بدون overflow أفقي للمهام الأساسية. |
| اللمس | الأزرار والحقول الرئيسية لا تقل عن `40px`؛ هذا أقرب من هدف 44px ويحتاج تحقق جهاز فعلي لاحقًا. |

## التحسينات المنفذة

- حل مشكلة تداخل لوح السيناريو عند الشاشة الكثيفة: لا يصبح sticky إلا عند `2xl`.
- إضافة روابط تخطي وظهور تركيز واضح.
- إضافة حبس تركيز وEscape وإعادة تركيز للبحث والدرج وحوار التأكيد.
- اعتماد IDs وtimestamps وunits وhashes بصياغة LTR داخل واجهة RTL.
- إظهار حالات source/trust بنص عربي وأيقونة، لا باللون فقط.

## غير مثبت بعد

- لم ينفذ اختبار قارئ شاشة يدوي مع NVDA أو VoiceOver أو TalkBack.
- لم يراجع مختص وصولية تباين كل حالة في كل موضوع بصري أو على شاشة فعلية.
- لم يختبر عرض لمس command-center فعلًا أو تكبير متصفح مرتفع أو إدخال صوتي.
- لا يوجد ادعاء امتثال كامل WCAG 2.2 AA؛ هذا هدف عملي لا شهادة.

## متابعة مطلوبة

قبل الإطلاق الإنتاجي، نفّذ تدقيق قارئ شاشة وتباين وأهداف لمس ببيئات مساعدة حقيقية، ثم وثّق العيوب وحلها بقبول صريح.
