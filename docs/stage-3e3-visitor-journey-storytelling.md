# قصة رحلة الزائر

## الوظيفة

تعرض خمس محطات مرشحة بترتيب مضبوط مع تشغيل وإيقاف مؤقت ومتابعة وسابق وتالٍ وإعادة وإيقاف. الاختيار مشترك مع خريطة التجربة وخريطة القيادة.

## حدود المحتوى

يظهر الاسم العربي والإنجليزي الموثق وحالة المصدر والهندسة والمحتوى. عندما لا توجد قصة معتمدة، يظهر النص: `لا يوجد محتوى سردي معتمد لهذه المحطة` بدل إنشاء وصف.

## حدود المسار والزمن

الانتقال منطقي للعرض، وليس مسارًا جغرافيًا. المدد `null` وسلطتها `unknown`. لا تتغير baseline أو scenario أثناء التشغيل.

## معاينة العرض

توجد معاينة full-screen نظيفة لهوية الفعالية والمحطة والتقدم والإفصاح. هي Storytelling preview فقط، وليست إسقاطًا نهائيًا أو معايرة أو تحكمًا ماديًا.
