# سجل رحلات KAP المرشحة من V.11

## قاعدة الهوية

الحروف A–P علامات محلية داخل الصفحة وليست هويات مكانية. هوية النقطة القانونية هي:

`<journeyId>-WP-<sourceLetter>`

كل نقطة تحفظ الصفحة والحرف والنص والمدة ونوعها الدلالي وأرجل الحركة الواردة والصادرة وحالة الربط وسلطة المصدر والتسجيل المكاني. القيمة `null` تعني أن المصدر لم يثبت العلاقة، ولا تُملأ بالتخمين.

## نقاط التماس الجديدة

هذه هويات مراجعة مرشحة وليست كيانات مكانية أو هندسة معتمدة:

- `TOUCHPOINT-KAP-FAMILY-GARDEN-CANDIDATE`
- `TOUCHPOINT-KAP-DEVONIAN-GARDEN-CANDIDATE`
- `TOUCHPOINT-KAP-MODERN-GARDEN-CANDIDATE`
- `TOUCHPOINT-KAP-POLYNESIAN-GARDEN-CANDIDATE`
- `TOUCHPOINT-KAP-OPTIONS-GARDEN-CANDIDATE`
- `TOUCHPOINT-KAP-EXTERNAL-NATURE-GARDEN-CANDIDATE`

يبقى اختلاف «الحديقة الحديثة» و«حديقة الحياة الحديثة» تعارض مصطلح مفتوحًا.

## عناصر لا تُربط تلقائيًا

- الصورة الأيقونية.
- العرضة السعودية.
- تسليم أو توزيع الهدايا.
- نقطة النزول.
- نقطة نهاية الرحلة.

هذه عناصر برنامج أو خدمة أو نقاط فرعية محتملة. لا يمنح وجودها مرساة مكانية.
