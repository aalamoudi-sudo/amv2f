# EX.1F — سجل الشخصيات والرحلات

## الشخصيات العامة

| المنظور | الأساس | التصنيف |
|---|---|---|
| ضيف ملكي وكبير الشخصيات | جمهور مصدر مرشح | source-backed-candidate |
| ضيف حكومي رفيع | جمهور مصدر مرشح | source-backed-candidate |
| قيادة الجهة المضيفة | تفسير تجربة | source-backed-candidate |
| ممثل إعلامي | جمهور مصدر مرشح | source-backed-candidate |
| موظف أو فرد من العائلة | جمهور مصدر مرشح | source-backed-candidate |
| ضيف من كبار الشخصيات | تفسير تجربة | source-backed-candidate |
| مشرف العمليات | منظور اختبار فجوات | rehearsal-only |
| فريق المراسم | منظور اختبار فجوات | rehearsal-only |
| فريق الأمن والسلامة | منظور اختبار فجوات | rehearsal-only |
| فريق المحتوى والإنتاج | منظور اختبار فجوات | rehearsal-only |
| دعم إتاحة الوصول | منظور اختبار فجوات | rehearsal-only |

تطبيق 11 منظورًا على الأيام الأربعة ينتج 44 متغير شخصية. المنظورات المصنفة `rehearsal-only` لا تثبت وجود فريق أو تكليف أو مالك.

## حجم البروفة المحفوظ

- 45 لحظة برنامج: 9 + 11 + 11 + 14.
- 44 متغير شخصية.
- 495 خطوة تنفيذ مرشحة، ناتجة حتميًا عن اللحظات لكل يوم × 11 منظورًا.

## قواعد الرحلة

- `JourneyCandidate` لا يحمل `SpatialRoute` معتمدًا.
- كل خطوة تربط اللحظة والشخصية والوجهة والمشهد مع بقاء IDs الأصلية.
- الاختيار اليدوي يوقف البروفة، ولا يغير الجاهزية أو الأدلة.
- `ZONE-SHOW-001` يبقى دلاليًا بلا مرساة.
- المعالم 004 و005 و011 تبقى مستقلة ولا تضاف تلقائيًا إلى رحلة الضيف.
- اليوم الثالث يرتبط بثلاثة `RoutePlanCandidate` كلها `selected=false`.
