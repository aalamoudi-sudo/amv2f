# EX.1F Studio 3D and 360 Delivery Intake

## Receive Mahmoud's Package

1. Place the complete unchanged package under `private-input/studio-3d-delivery/`.
2. Include native sources, exports, textures, proxies, XREFs, fonts, plugins and camera metadata.
3. Run `pnpm intake:experience-studio`.
4. Review inventory, hashes, dependency findings, format capability and quarantine output.
5. Correct missing, external or broken dependencies before review acceptance.
6. Validate rights, scale, units, origin, north, coordinate reference and spatial registration separately.
7. Generate non-destructive optimization previews only from valid source geometry.
8. Map candidate assets to existing destination and scene IDs.
9. Obtain Ahmed's candidate-review decision.
10. Bind through the existing Scene Gateway as one atomic candidate revision.

The normal inventory is path-redacted. A separate ignored, mode-`0600` private custody report retains exact local filenames and source paths for Mahmoud's correction work; it is never sent to the browser, Git, a review ZIP or the client deployment package.

## Honest Capability Classes

- `inventory-only`
- `metadata-readable`
- `structurally-validatable`
- `previewable`
- `runtime-compatible`
- `requires-native-software`
- `requires-export`
- `requires-optimization`
- `unsupported`
- `quarantined`

MAX, SKP, RVT and similar native formats are inventory-only or require their verified native software/export flow. Recognition is not conversion support.

## Runtime Assets

GLB/glTF validation checks the container, JSON, buffers, URIs, hierarchy, meshes, materials, animation references, extensions, approximate geometry size and bounds before Scene Gateway access. Panoramas must be true equirectangular 2:1 images, preferably 8192x4096 and at least 4096x2048 for review. Flat renders remain flat references. GPS must be removed from client derivatives; the accelerator only detects and blocks or quarantines it and does not claim that a derivative has already been produced.
