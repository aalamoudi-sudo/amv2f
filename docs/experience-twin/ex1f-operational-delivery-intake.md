## Supported Intake Types

The inventory recognizes PDF, XLSX, CSV, DOCX, PPTX, JSON and locally inspected ZIP. Recognition is not a claim that every semantic field can be extracted. Unsupported extraction stays `inventory-created` or `incomplete`. Exact local filenames and paths remain only in the ignored private custody report; the browser projection receives safe display names and opaque IDs.

## Reconciliation Slots

The controlled model can receive four-day schedules, detailed timings, moments, personas, arrivals, entrance and movement proposals, route candidates, destinations, ownership, responsible parties, verification and approval authorities, evidence rules, dependencies, contingencies, restrictions and conflicts.

No reconciliation step selects between conflicting routes, promotes a narrative sequence to `SpatialRoute`, accepts file metadata as authority, or changes readiness.

## Corrections

A changed source receives a new source fingerprint and revision. A matching duplicate does not create a false revision. Conflicting duplicate content is quarantined for explicit review. There is no last-write-wins behavior.
