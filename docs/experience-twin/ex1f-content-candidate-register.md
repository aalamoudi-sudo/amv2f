# EX.1F — سجل مرشحي المحتوى

## العرض الرئيسي

1. الرياض من الفتح حتى الحدائق.
2. دقات الأرض.
3. تقدير ملك لملك.
4. سيرة الأرض.
5. سفينة البقاء.

كلها `proposed` و`not-approved`. لا يوجد اختيار نهائي أو master تشغيلي.

## الأفلام التعريفية

| المرشح | المدة المصدرية |
|---|---:|
| رحلة الزمن الأخضر | قرابة 3 دقائق |
| بين هلالين | قرابة 3 دقائق |
| هدية خضراء للعالم | قرابة 3 دقائق |

المدة مرجع محتوى وليست cue تشغيليًا معتمدًا.

## ممر العصور / أرشيف الأرض

الاسم التشغيلي المؤسس هو **ممر العصور**. **أرشيف الأرض** اسم إبداعي مرشح مرتبط دلاليًا فقط.

| المحطة | المدة المصدرية المرشحة |
|---|---:|
| الديفوني | 3 دقائق |
| الكربوني | دقيقتان |
| البرمي | دقيقتان |
| الترياسي | دقيقتان |
| الجوراسي | دقيقتان |
| الطباشيري | دقيقتان |
| العصر الحديث | دقيقتان |

التقنيات المذكورة: هياكل شفافة، إسقاط داخلي، شاشات LED شفافة، رسوم نباتية، ضباب مؤثر، وصوت محيطي. كلها اقتراحات إبداعية محايدة للمورد، وليست مواصفات أو شراء أو تكاملًا معتمدًا.
