# EX.1F — قائمة قبول المؤسس

لا تُعد أي خانة مقبولة تلقائيًا. يستخدم أحمد هذه القائمة أثناء المراجعة النهائية الواحدة.

## المنتج

- [ ] المدخل الواحد يوضح المشروع واليوم والشخصية واللحظة خلال خمس ثوانٍ.
- [ ] النظرة المتكاملة والخريطة والمشهد والبروفة تبدو منتجًا واحدًا.
- [ ] عرض العميل ذو 14 خطوة مناسب للعرض العربي RTL.
- [ ] الفرق المرئي عن EX.1D جوهري وليس تجميليًا فقط.

## الحقيقة

- [ ] المصادر الثلاثة ظاهرة كمرشحات عمل مقدمة من المؤسس فقط.
- [ ] اليوم الثاني وحضوره وانتقاله يبقون مجهولين.
- [ ] بدائل اليوم الثالث الثلاثة ظاهرة وغير مختارة.
- [ ] ممر العصور هو الاسم التشغيلي، وأرشيف الأرض اسم إبداعي مرشح.
- [ ] العرض يبقى بلا مرساة.
- [ ] KAP يبقى `cannot-determine` دون نسبة.

## المحتوى والأصول

- [ ] مرشحو العرض والأفلام والمحطات ظاهرون دون اعتماد.
- [ ] الصور المسطحة لا تظهر كـ360.
- [ ] 360 وGLB الإنتاجي يظهران مفقودين.

## السلامة والخصوصية

- [ ] تفاصيل HSE المقيدة غير موجودة في واجهة العميل أو ZIP.
- [ ] لا PII أو GPS أو أسرار أو ملفات خام.
- [ ] لا ادعاء هندسة أو مسار أو جاهزية أو افتتاح.

## القرار

- [ ] قرار أحمد يسجل بعد المراجعة؛ هذه القائمة لا تمنح القبول بذاتها.
