# KAGA Experience Map

The experience follows an executive narrative with the spatial masterplan as its backbone.

```text
Intro
  -> Four days
       -> linked journey -> Masterplan / route playback
       -> linked activation -> Experience focus
  -> Masterplan
       -> stop inspector -> linked visual experience
  -> Royal moment -> Launch show
  -> Experiences -> return to Masterplan
  -> Mobile exhibition
  -> Invitation proposal
  -> Identity applications
  -> Visual museum
```

Presenter Mode moves navigation into a reduced floating controller, hides document chrome, suppresses page scrolling, supports previous/next keyboard navigation, and exits with Escape. Fullscreen is requested through the browser API but the experience remains usable if the browser denies it.

The royal moment and launch show are explicitly approved-concept visualizations. The invitation path is explicitly an interactive proposal demonstration. Neither surface claims physical accuracy, production connectivity, real guest data, or operational authority.
