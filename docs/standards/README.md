# معايير Mayadeen Event Intelligence OS

هذا المجلد هو المرجع الرسمي للمعايير التي تتكرر عبر جميع الفعاليات.

## الوثائق الحالية

1. `physical-digital-twin-standard-v1.0.md`

   Core Standard المجمد للتوأم الرقمي الفيزيائي.

2. `approved-equipment-list.md`

   قائمة المنتجات والتقنيات المرشحة أو المؤهلة، ويمكن تحديثها دون تغيير Core.

3. `physical-deployment-profile-template.md`

   قالب تهيئة كل فعالية وإثبات مطابقتها.

## قاعدة الاستخدام

- Core Standard يحدد العقود والنتائج ولا يخصص لفعالية.
- AEL يحدد الأجهزة القابلة للتبديل وحالتها.
- Project Configuration يحمل بيانات الفعالية واختياراتها فقط.
- أي انحراف يسجل Waiver ولا يغيّر المعيار.
- لا يعد أي معيار تصريح شراء أو بدء مرحلة دون موافقة أحمد المطلوبة في
  `docs/rd-charter.md`.
