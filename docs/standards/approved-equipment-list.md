# قائمة المعدات والتقنيات المعتمدة

**المرجع:** `MEIOS-PDT-AEL-001`

**الإصدار:** `1.0.0`

**آخر مراجعة:** 2026-07-11

**المعيار الحاكم:** `MEIOS-PDT-STD-001 v1.0.0`

## 1. الغرض

هذه القائمة تفصل المنتجات المتغيرة عن Core Standard الثابت. وجود جهاز في
القائمة لا يغير المعيار، ولا يعد تصريح شراء. يجب أن يختار كل مشروع جهازًا مناسبًا
لدراسة الموقع ويجتاز اختبارات القبول.

## 2. حالات التأهيل

| الحالة | المعنى |
| --- | --- |
| `Candidate` | مرشح ورقيًا، ولم يجتز اختبارًا ماديًا من ميادين |
| `Provisional Approved` | صالح لـPrototype أو استخدام محدود بشروط واضحة |
| `Qualified` | اجتاز اختبار التأهيل على ملف تنفيذ محدد |
| `Approved` | اجتاز التأهيل والقبول التشغيلي للاستخدام المحدد |
| `Deprecated` | يعمل في المشاريع القائمة، ولا يختار لمشروع جديد |
| `Retired` | ممنوع للمشاريع الجديدة ولا يدعم إلا بخطة انتقال |

## 4. متطلبات فئة المعدات البديلة

### 4.1 طابعة بديلة

- تحقق حجم الوحدة المطلوبة في Profile.
- فوهتا 0.4 و0.6 مم أو مكافئتان.
- استئناف طباعة، معايرة آلية، وملف تشغيل قابل للحفظ.
- قطع غيار ودعم محلي أو خطة استبدال موثقة.
- اجتياز First Article وسماحات التصنيع في Core Standard.

### 4.2 بروجكتر بديل

- Solid-State/Laser.
- WUXGA أصلي على الأقل لـ`PDT-M`.
- تحكم LAN أو RS232.
- تركيب ثابت وسلك سلامة.
- نجاح Projection Study واختبار عينة مادية.
- إثبات تغطية الأسطح الحرجة ومعايير التطابق والتباين.

### 4.3 Projection Adapter بديل

- يدعم عقد REST/WebSocket بإصدار محدد أو Adapter رسميًا له.
- يدعم Warp وMask وBlend وحفظ ملف المعايرة.
- يعمل محليًا دون اعتماد إلزامي على الإنترنت.
- يوفر Export ونسخة احتياطية وخطة استعادة.
- لا يحتوي Domain Logic ولا يغيّر baseline.

## 6. قواعد تحديث القائمة

1. تحديث هذه القائمة لا يغير Core Standard.
2. لا تنتقل حالة أي منتج إلى `Qualified` أو `Approved` دون تقرير اختبار.
3. توقف الإنتاج أو ضعف الضمان يغيّر الحالة إلى `Deprecated` أو `Retired`.
4. Firmware أو Software مؤثر يسجل كإصدار مستقل ويحتاج Regression Test.
5. المشروع يجمّد نسخة AEL المستخدمة عند Kickoff.
6. لا يقبل بديل من المورد دون موافقة مكتوبة واختبار مطابق.

## 7. الاختبارات المطلوبة للترقية إلى Approved

- تقرير First Article للطباعة.
- تقرير Projection Study.
- اختبار قبول 8 ساعات.
- قياس خطأ التطابق وP95 latency وfps.
- حفظ واستعادة Calibration Profile.
- اختبار انقطاع الشبكة وSnapshot Recovery.
- اختبار Blackout والاستعادة.
- فحص الضمان، قطع الغيار، والتشغيل المحلي.
