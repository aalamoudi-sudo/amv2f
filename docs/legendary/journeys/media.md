# مسار الإعلاميين

المصدر: عرض التدشين، صفحة 35. الزمن المصدري: 04:30–09:00 م. يتقدم المسار من النقل الترددي والاستقبال إلى الجولة، ثم الضيافة والمؤتمر الصحفي والعشاء والهدايا والخروج. المؤتمر الصحفي هو المشهد المميز المصدرّي.

الرحلة الخارجية لحديقة الطبيعة تبقى فرعاً اختيارياً مستقلاً ولا تظهر ضمن تشغيل القصة الرئيسي.
