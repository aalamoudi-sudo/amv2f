# Legendary L2 Architecture

L2 adds orchestration without rewriting KAGA data. One Zustand `LegendarySystemSession` owns the current day, journey, beat, stop, spatial focus, lens, Director scope, progress, experience, knowledge, and return context.

The four lenses are projections of that state:

- Story: day chronology and key moments.
- Place: the frozen source masterplan and deterministic relationships.
- Guest: six independently authored journey stories.
- Experience: approved experiences with sourced who/when/where.

Lens switching changes only `lens`; day/journey/stop/progress remain. Director Mode operates real map, Royal Moment, Launch Show, experiences, and source assets. It is live UI, not recorded media. Exploration snapshots the complete orchestration context and resume restores it exactly.

No shortest-path calculation, new geometry, inferred clock time, or fabricated physical position exists in L2.
