# دليل حزمة KAGA التنفيذية

هذا الدليل يخص أرشيف المطور الداخلي `KAGA-Final-Developer-Archive.zip`. حزمة العرض الخارجية المنفصلة `KAGA-Executive-Presentation.zip` تحتوي على البناء وملفات التشغيل فقط.

تحتوي حزمة التسليم على:

- `app/`: بناء الإنتاج الجاهز للعمل محلياً دون اتصال.
- `source/`: الشفرة المصدرية والاختبارات وملفات الإعداد والتوثيق.
- `source/docs/`: معمارية التجربة، خرائط المصدر، نموذج الرحلات، تقرير QA والقيود المعروفة.
- `reports/`: التقرير التنفيذي العربي ولقطات المراجعة.

## تشغيل البناء الجاهز

من داخل مجلد الحزمة شغّل خادماً ثابتاً محلياً على مجلد `app/`، ثم افتح الصفحة الرئيسية. لا يحتاج العرض إلى إنترنت أو إلى خدمة خلفية.

## إعادة البناء من المصدر

1. انسخ مجلد `app/kaga/` إلى `source/public/kaga/` حتى تكون الأصول المصدرية والوثيقة الأصلية متاحة للبناء من دون تكرارها داخل ملف ZIP.
2. ثبّت الاعتماديات من ملف القفل.
3. شغّل `pnpm build:kaga`.

الأصول محفوظة مرة واحدة فقط داخل الحزمة لتقليل الحجم. لا تتضمن الحزمة `node_modules` أو مجلدات الذاكرة المؤقتة أو فيديوهات الاختبار.
