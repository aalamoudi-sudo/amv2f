# Illustrated Map QA

- AI SHA-256 verified before extraction.
- Raw AI absent from `public/`, build and review package.
- Source-true SVG, route paths, pathProgress and registered spatial files unchanged.
- All six map hotspots correspond to `executiveGardenRegistrations`.

## Visual checks
