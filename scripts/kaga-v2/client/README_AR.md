# تجربة تدشين حدائق الملك عبدالله — KAGA V2

هذه الحزمة مخصصة للعرض التنفيذي المحلي، وتعمل دون اتصال بعد تشغيل خادم ملفات
محلي بسيط.

## التشغيل السريع

- macOS: افتح `START_KAGA.command`.
- Windows: افتح `START_KAGA_WINDOWS.bat`.
- أو شغّل أي خادم ملفات ثابت من داخل مجلد `app/` ثم افتح الصفحة الرئيسية.

يتطلب المشغّل السريع وجود Python 3. لا تعتمد التجربة على خادم خلفي أو اتصال
شبكي خارجي. يحتفظ مجلد `app/kaga/source/` بالوثيقة الأصلية اللازمة لرابط
«الوثيقة الأصلية» داخل العرض.

## الدقة الموصى بها

- 1920×1080
- 2560×1080
- 2560×1440

لأفضل عرض، استخدم «وضع التقديم» من داخل التجربة ثم فعّل ملء الشاشة.
