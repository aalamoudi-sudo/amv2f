# KAGA FINAL EXPERIENCE

هذه الحزمة هي النسخة التنفيذية النهائية لتجربة تدشين حدائق الملك عبدالله.

## التشغيل

يفضّل تشغيل المجلد `app` عبر خادم ملفات ثابت محلي. يمكن استخدام ملف التشغيل المناسب للنظام:

- macOS: `START_KAGA.command`
- Windows: `START_KAGA_WINDOWS.bat`

ثم تُفتح التجربة على `http://127.0.0.1:4176`.

لا تحتاج التجربة إلى اتصال بالإنترنت أو خادم خلفي. الوثيقة الأصلية موجودة داخل الحزمة ويصل إليها زر `الوثيقة الأصلية`.
