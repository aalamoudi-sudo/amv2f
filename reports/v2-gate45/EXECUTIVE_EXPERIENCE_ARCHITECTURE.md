# KAGA V2 — Executive Experience Architecture

## Outcome

Gate 4/5 turns the approved spatial and knowledge contracts into one Arabic-first executive experience. It preserves the frozen source geometry, six garden registrations, six journey semantics, optional branches, and the common `pathProgress` timeline.

## Experience worlds

| World | Executive purpose | Preserved source model |
| --- | --- | --- |
| Intro | Establish identity and two entry paths | Event cover visual + Knowledge Guide scale |
| Project Scale | Establish size without dashboard cards | +2M m², +1M plants, 15 gardens, 7/8 split |
| Four Days | Present four ceremonial chapters | Event PDF day/date/location/attendance data |
| Event Map | Play six inauguration journeys | Registered journey geometry and shared timeline |
| Garden Explorer | Discover physical and textual garden knowledge | Six registered footprints + thirteen textual entities |
| Crescent Story | Connect deep time to inauguration | Knowledge Guide story; no map claim |
| Royal Moment / Launch | Present the ceremonial sequence | Existing event logic and approved source visuals |
| Experiences | Connect hospitality and activations to place | Existing source-backed experience manifest |
| Mobile Exhibition | Preserve question → capsule → response | Seven Event PDF questions; optional guide enrichment |
| Invitations | Explain the proposal workflow | Existing deterministic demo only |
| Visual Identity / Museum | Present approved applications and renders | Lazy-loaded asset manifests |

## State continuity

Journey-to-place discovery stores journey ID, exact progress, active stop, and playback state before opening Garden Detail. `العودة إلى الرحلة` restores the same journey, marker anchor, stop inspector, and playback state where appropriate.

## Executive and provenance separation

Default mode contains natural Arabic executive language only. Development provenance is available only when the app runs in development with `?provenance=1`, and exposes source pages, spatial designations, registration confidence, and route audit records. It is absent from Presenter Mode and production executive navigation.

## Performance boundary

- The raw 3DM is never shipped at runtime.
- The frozen 2D source and derived registered layer are unchanged.
- Visual Museum and noncritical interactive modules load on demand.
- Source renders remain asset-manifest driven.
